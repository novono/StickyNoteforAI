贴贴的首个可直接下载版本。无需 Xcode、Python 或自行编译。

### 下载与安装

- **推荐：`PaperMemory-macOS-arm64.dmg`**。打开后，将 `PaperMemory.app` 拖到 `Applications`，再从“应用程序”启动。
- `PaperMemory-macOS-arm64.zip` 是相同应用的压缩包，解压后移入“应用程序”即可。
- `SHA256SUMS` 提供两个安装包的 SHA-256 校验值。GitHub 自动生成的 **Source code** 是源码，不是安装包。

支持 **Apple 芯片（M 系列）Mac、macOS 14 或更新版本**；此安装包不支持 Intel Mac。应用与手写字体都包含在下载中，使用便签不需要联网。

### 首次打开

此版本采用 ad-hoc 签名，**尚未经过 Apple Developer ID 签名与公证**。首次打开若被系统阻止，请先尝试打开应用，再到“系统设置 → 隐私与安全性 → 仍要打开”，按系统提示确认。请确认文件来自本仓库；不需要关闭系统安全检查。参见 [Apple 的打开说明](https://support.apple.com/zh-cn/102445)。

应用常驻菜单栏，没有 Dock 图标。更新时先退出旧版贴贴，再替换应用；原有便签保存在用户资料目录中。

### 包含的功能

- 多张无顶栏便签，直接书写、同一张纸展开详情并粘贴图片。
- 中英文细笔手写字体、三档字号、四种纸色、文字删除线。
- 右下卷角、贴上与撕走动画、拖动惯性、缓慢纸张老化。
- 桌面层与置顶切换，置顶锁标识可一键解除。
- 本地 MCP / CLI，支持 AI 创建、读取、更新、归类和附图。
- 新应用图标，以及 Codex、Claude Desktop、Claude Code、Cursor 接入教程。

安装后继续阅读 [AI 接入教程](https://github.com/novono/StickyNoteforAI/blob/v1.3.1/docs/AI-CLIENTS.md) 或 [完整使用说明](https://github.com/novono/StickyNoteforAI/blob/v1.3.1/README.md)。
