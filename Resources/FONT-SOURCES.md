PaperKai, PaperXing, PaperCao, PaperLatinKai, PaperLatinXing and PaperLatinCao are modified Light derivatives created for PaperMemory in October 2026. They use gently inset outlines to make the strokes lighter at desktop note sizes. They have been renamed to avoid use of the original reserved font names. Original copyright and OFL notices remain in the font metadata and accompanying license files. These derivative fonts are also licensed under SIL OFL 1.1 and are distributed with the application, not sold separately.

The reproducible build script `scripts/make-light-fonts.py` is included in the source distribution. Font outlines and shaping tables are retained; the static Caveat instance uses weight 400 as its source before the outline adjustment. Original fonts remain bundled for attribution and fallback.
